# NEXA

## Mobile Application Programming – CSC 402

NEXA is a mobile application designed to help university students manage collaborative academic projects in one centralized platform.

## Project Overview

University students often manage group projects using separate messaging platforms, file-sharing services, and calendars. This can lead to unclear responsibilities, missed deadlines, and difficulties tracking project progress.

NEXA brings essential project management activities together in one mobile application, helping students organize their work, communicate more effectively, and keep track of their project progress.

## Target Users

NEXA is primarily designed for university students who frequently work on collaborative academic projects.

The application helps students:

- Organize project tasks
- Assign responsibilities
- Track project progress
- Manage deadlines
- Share project files
- Stay updated on important activities

## Core Features

### User Registration & Login
Students can create an account and securely log in to access their projects.

### Create & Manage Projects
Users can create projects, add project details, and manage their active projects.

### Join Project / Team
Students can join a project using a project code or invitation.

### Task Management
Team members can create, assign, edit, and complete tasks.

### Task Deadlines
Users can set deadlines for tasks and view upcoming deadlines.

### Project Progress Tracking
The application displays overall project progress based on completed and remaining tasks.

### Team Members
Users can view team members and their assigned responsibilities.

### File Sharing
Team members can upload and access files related to their project.

### Notifications & Reminders
Users receive reminders about upcoming deadlines and task updates.

### Project Calendar
Users can view project deadlines and important dates in a calendar.

### Task Comments
Team members can comment on tasks to discuss updates or requirements.

### Dashboard
The dashboard provides an overview of active projects, pending tasks, completed tasks, and upcoming deadlines.

### Profile Management
Users can view and update their profile information.

### Search & Filter Tasks
Users can search and filter tasks by status, deadline, or assigned member.

### Project Activity Log
The activity log displays recent project activities such as completed tasks, new files, and task assignments.
