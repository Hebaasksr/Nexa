# NEXA Style Guide

## Colors
- Primary: Electric Purple (#6133E0)
- Background: Deep Navy (#040514)
- Accent: Cyan/Teal (#11A7B6)
- Error: Red (#B02038)
- Success: Green
- Warning: Amber

## Typography
- Clean sans-serif font (Inter-style)
- Material 3 typography hierarchy:
  Headline, Title, Body, Label

## Spacing and Shapes
- 8 dp spacing grid
- Rounded cards
- Pill-shaped buttons and tabs

## UI Components
- Button / OutlinedButton
- OutlinedTextField
- Card
- NavigationBar
- TopAppBar
- TabRow
- LinearProgressIndicator
- AlertDialog
- Switch
- Checkbox
- Dropdown Menu
- Date Picker
